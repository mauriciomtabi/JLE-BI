  Row 2:  | 1. A planilha Modelo do Fluxo de Caixa possui duas abas principais: Fluxo de Caixa e Origem de Dados.  |  |  |  |  |  | 
  Row 3:  | 2. Como preencher a aba Fluxo de Caixa: 
a. Comece preenchendo a célula I8 com o valor do saldo inicial (que é o saldo em caixa quando começar a usar a planilha). 
b. As colunas Entrada / Saída - Receitas / Despesas e Tipo Transaçao estao predefinidas. Basta escolher na seta a opçao desejada para completar a célula. 
c. As colunas Data, Detalhamento e R$ (Valores) devem ser preenchidas manualmente.  
d. Para inserir uma nova linha na planilha, basta preencher a coluna data e seguir com as demais. Por ser uma tabela dinâmica, ela incorporará a fórmula automaticamente. 

Importante: a planilha está preenchida para melhor entendimento de seu funcionamento. Basta apagar as informaçoes para dar início a sua planilha customizável. A linha do saldo inicial pode ter datas e valores alteradas, mas nao deve ser apagada.  |  |  |  |  |  | 
  Row 4:  | 3. Como usar a aba Fluxo de Caixa:  Por meio das caixas de filtros Entrada/Saída e Mês (localizadas no topo da planilha), é possível comparar diversos dados, Entrada, Saída ou Saldo. Basta escolher qual valor ou valores que quer verificar e selecionar o mês ou meses. Se nao selecionar nada, terá a visao completa da movimentaçao.   |  |  |  |  |  |
